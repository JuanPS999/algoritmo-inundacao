===== BUILD.SH =====
#!/usr/bin/env bash
# Compila o projeto (alvo: Java 8).
# Cenario A: javac 1.8 (faculdade) -> compila direto, JavaFX embutido.
# Cenario B: javac novo + OpenJFX -> usa jars do JavaFX no classpath e --release 8
#            (fallback: -source 8 -target 8).
set -e
cd "$(dirname "$0")"

mkdir -p build

detect_javafx_lib() {
  if [ -n "$JAVAFX_LIB" ]; then echo "$JAVAFX_LIB"; return; fi
  for d in /usr/lib/jvm/java-*-openjdk/lib /usr/lib/jvm/*/lib /usr/share/openjfx/lib /usr/lib/jvm/javafx*/lib; do
    if [ -f "$d/javafx.controls.jar" ]; then echo "$d"; return; fi
  done
  echo ""
}

if javac -version 2>&1 | grep -q '1\.8'; then
  echo "javac 1.8 detectado: compilando direto (JavaFX embutido)."
  find . -name '*.java' -not -path '*/build/*' > sources.txt
  javac -d build @sources.txt
else
  JAVAFX_LIB="$(detect_javafx_lib)"
  if [ -z "$JAVAFX_LIB" ]; then
    echo "ERRO: JavaFX nao encontrado. Defina JAVAFX_LIB apontando para a pasta lib do OpenJFX." >&2
    exit 1
  fi
  echo "javac moderno detectado; JavaFX em: $JAVAFX_LIB"
  find . -name '*.java' -not -path '*/build/*' > sources.txt
  CP="$JAVAFX_LIB/javafx.base.jar:$JAVAFX_LIB/javafx.graphics.jar:$JAVAFX_LIB/javafx.controls.jar"
  if ! javac --release 8 -cp "$CP" -d build @sources.txt 2>/dev/null; then
    echo "--release 8 falhou; tentando -source 8 -target 8."
    javac -source 8 -target 8 -cp "$CP" -d build @sources.txt
  fi
fi

echo "Compilacao OK."

# Executa a aplicacao (GUI por padrao; repassa argumentos ao FloodingApp).

cd "$(dirname "$0")"

if java -version 2>&1 | grep -q '1\.8'; then
  # JDK 1.8: JavaFX embutido, sem module-path.
  java -cp build view.FloodingApp "$@"
else
  if [ -z "$JAVAFX_LIB" ]; then
    for d in /usr/lib/jvm/java-*-openjdk/lib /usr/lib/jvm/*/lib /usr/share/openjfx/lib /usr/lib/jvm/javafx*/lib; do

fi

===== README.MD =====
# Roteamento por Inundacao - Redes de Computadores II (UESB)

Trabalho academico: implementacao de 4 versoes de roteamento por inundacao
com GUI em JavaFX e medicao de pacotes gerados ate o destino.

## Requisitos
- JDK 1.8.0_351 com JavaFX embutido (jre/lib/ext/jfxrt.jar)
- `javac -version` deve mostrar 1.8.x

## Build e Execucao

### Compilar
```bash
./build.sh
```
Compila todos os .java para a pasta `build/`.

### GUI (modo ao vivo)
```bash
./run.sh
```
Janela com grafo, controles, tabela de resultados e menu.
- ComboBox versao (1 a 4), transmissor, receptor
- Spinner TTL (versoes 3 e 4), Slider velocidade (0.25x a 10x)
- Botoes: Iniciar, Pausar, Resetar
- Spinner N (default 30), botao "Executar N vezes" (modo lote)
- Clique em aresta: alterna habilitado/desabilitado (vermelho tracejado)
- Transmissor verde, receptor azul (laranja quando atingido)
- Contador ao vivo e snapshot na primeira chegada
- Tabela V1-V4: Ultima, N, Media, Desvio

### Console (execucao unica)
```bash
java -cp build util.ConsoleRunner <versao> <origem> <destino> <ttl> <semente>
```
Exemplo:
```bash
java -cp build util.ConsoleRunner 3 1 4 3 42
```
Imprime eventos (transmissao/chegada) e snapshot final.

### Lote em linha de comando (todas versoes)
```bash
java -cp build util.BatchConsole <n> <origem> <destino> <ttl> <sementeBase> [backbone]
```
Exemplo:
```bash
java -cp build util.BatchConsole 30 1 4 3 42
```
Imprime CSV: Versao,Validas,Abortadas,Inalcancaveis,Media,DesvioPadrao

## Formato do backbone.txt
```
N;
A;B;PESO
...
```
- Primeira linha: numero de nos (pode terminar com `;`)
- Demais linhas: aresta nao direcionada (listada uma vez)
- Exemplo (grafo Tanenbaum, 8 nos):
```
8;
1;2;2
1;7;6
2;3;7
2;5;2
3;6;3
3;4;3
4;8;2
5;7;1
5;6;2
6;8;2
7;8;4
```
- Rotulos na GUI: 1->A, 2->B, ... (interno usa numericos 1..N)

## Versoes do Algoritmo
- **V1**: Cada pacote que chega e enviado por TODAS as interfaces.
- **V2**: Igual a V1, EXCETO pela interface de chegada.
- **V3**: Igual a V2, mais verificacao/decremento de TTL (descarte se TTL <= 0).
- **V4**: Baseada na V3, adiciona deduplicacao temporal por no. Cada no mantem registro do instante da ultima observacao de cada messageId. Se uma copia chegar dentro da janela configurada (windowMs), e descartada como duplicata (nao reencaminhada, nao renova o registro). Com window=0, V4 equivale a V3.

## Modo Lote (GUI)
- Botao "Executar N vezes" roda N execucoes (default 30) em thread daemon.
- Semente base fixa 42 + i para cada execucao.
- Sem animacao; usa BatchRunner.
- Execucoes validas (destino atingido) vao para a tabela (Media, Desvio).
- Abortadas (limite 2M pacotes) e inalcançaveis (fila vazia) ficam FORA da media.
- Botao desabilitado durante o lote; reabilitado ao fim (sucesso ou erro).

## Tempo Virtual
- Nucleo pull-based: PriorityQueue por instante de chegada, desempate FIFO.
- Sem Thread.sleep, sem thread por pacote/roteador.
- Latencia por transmissao: inteiro aleatorio [1, 500] ms (peso da aresta NAO influencia).
- TTL default = diametro do grafo em saltos (BFS), editavel na GUI.

3. Modelo da simulacao
Graph

Representa a topologia carregada de backbone.txt.

Os nos sao identificados por IDs e os enlaces conectam os nos. O peso do enlace representa o custo/peso da topologia e nao a latencia de transmissao.
Node

Representa um no da rede e suas conexoes.
Link

Representa um enlace entre dois nos. Enlaces desabilitados devem descartar transmisssoes.
Packet

Representa uma copia de pacote em transito.

Simulator

E o nucleo da simulacao.

A simulacao usa uma fila de prioridade de eventos. Eventos sao processados em ordem de tempo virtual; empates preservam a ordem de insercao.
4. Tempo e latencia

Cada transmissao recebe latencia aleatoria entre 1 ms e 500 ms.

A seed permite reproduzir a mesma sequencia pseudoaleatoria.

O peso do enlace nao representa a latencia.

O tempo da simulacao e virtual. Na GUI, o AnimationTimer converte tempo real em avanco de tempo virtual conforme a velocidade selecionada.
5. Entrega no destino

Quando um pacote chega ao destino:

    a chegada e validada;

    se for a primeira chegada, o snapshot e registrado;

    a estrategia ainda pode decidir encaminhar o pacote;

    as copias encaminhadas seguem normalmente.

O snapshot representa o numero de pacotes observado na primeira chegada ao destino.
6. Estrategias de inundacao
V1 - Todas as interfaces

Encaminha por todas as interfaces disponiveis. O enlace de entrada nao impede o encaminhamento. TTL nao limita V1.
V2 - Exceto interface de entrada

Encaminha por todas as interfaces, exceto aquela pela qual o pacote acabou de chegar.
V3 - TTL

Usa a logica da V2 e adiciona TTL:

    decrementa o TTL;

    encaminha se ainda puder ser encaminhado;

    reconhece a entrega no destino antes do descarte por TTL.

O TTL padrao pode ser calculado a partir do diametro do grafo.
V4 - Deduplicacao temporal

Usa a logica da V3 e adiciona deduplicacao temporal por no.

Possui windowMs, com padrao de 1000 ms.

O estado e mantido por no:

messageId -> instante da ultima observacao

Uma mensagem e duplicada quando:

tempoAtual - instanteVisto < windowMs

Duplicatas:

    nao sao encaminhadas;

    nao renovam o instante da observacao.

Entradas expiradas sao removidas somente durante consultas. Nao existem timers ou eventos separados para expiracao.

A origem e registrada como primeira observacao no instante zero.

Com windowMs = 0, V4 deve ser equivalente a V3.

/* ***************************************************************
* Autor............: Juan Prado Da Silva
* Matricula........: 202310291
* Inicio...........: 06/10/2026
* Ultima alteracao.: 06/10/2026
* Nome.............: BatchRunner
* Funcao...........: Executa multiplas simulacoes em lote (sem JavaFX)
*                    e agrega resultados estatisticos.
*************************************************************** */
package controller;

import java.util.ArrayList;
import java.util.List;

import model.Graph;
import model.LatencyProvider;
import model.RunResult;
import model.Simulator;

public class BatchRunner {

    /* ***************************************************************
    * Metodo: run
    * Funcao: executa 'count' simulacoes com sementes baseSeed + i,
    *         classifica resultados e devolve um BatchResult imutavel.
    * Parametros: graph = grafo de rede; version = versao da estrategia
    *             (1 a 4); sourceId = no transmissor; destinationId =
    *             no receptor; ttl = TTL inicial; count = numero de
    *             execucoes; baseSeed = semente base do LatencyProvider;
    *             windowMs = janela de deduplicacao para V4 (ignorado
    *             nas outras versoes)
    * Retorno: BatchResult com amostras, abortadas e inalcançaveis
    *************************************************************** */
    public static BatchResult run(Graph graph, int version, int sourceId,
            int destinationId, int ttl, int count, long baseSeed, long windowMs) {
        List<Long> samples = new ArrayList<Long>();
        int aborted = 0;
        int unreachable = 0;

        for (int i = 0; i < count; i++) {
            long seed = baseSeed + i;
            Simulator simulator = new Simulator(graph,
                    StrategyFactory.create(version, windowMs),
                    new LatencyProvider(seed),
                    sourceId, destinationId, ttl);
            RunResult result = simulator.runUntilFirstArrival();
            if (result.isReached()) {
                samples.add(Long.valueOf(result.getSnapshotCounter()));
            } else if (result.isAbortedByLimit()) {
                aborted++;
            } else {
                unreachable++;
            }
        }

        return new BatchResult(samples, aborted, unreachable);
    }//fim do metodo run

}//fim da classe BatchRunner

            snapshotShown = false;
            logLines.clear();
            newLogLines.clear();
            droppedLogLines = 0;
            graphPane.setEndpoints(sourceId, destinationId);
            graphPane.setDestinationReached(false);
            graphPane.clearPackets();
            controlPanel.resetDisplay();
            controlPanel.setEstado(view.ControlPanel.EstadoSimulacao.PAUSADO);
            controlPanel.setStatus("Modo passo a passo. Clique 'Proximo evento' para avancar.");
            controlPanel.setState("PAUSADO");
        }
        // pausa o timer se estiver rodando
        timer.stop();
        paused = true;
        controlPanel.setEstado(view.ControlPanel.EstadoSimulacao.PAUSADO);
        // avanca ate o proximo evento
        long nextTime = simulator.peekNextTime();
        if (nextTime != Long.MAX_VALUE) {
            simulator.advanceTo(nextTime);
            virtualClock = nextTime;
            refreshView();
            controlPanel.setNextEventTime(simulator.peekNextTime());
            controlPanel.setStatus("Avancado para t = " + virtualClock + " ms");
        } else {
            controlPanel.setNextEventTime(Long.MAX_VALUE);
            controlPanel.setStatus("Fila de eventos vazia.");
        }
    }//fim do metodo step

        }//fim do if

        lastFrameNanos = 0L;
        if (paused) {
            timer.stop();
        } else {
            timer.start();
        }
        controlPanel.setEstado(paused ? view.ControlPanel.EstadoSimulacao.PAUSADO
                : view.ControlPanel.EstadoSimulacao.RODANDO);
        controlPanel.setState(paused ? "PAUSADO" : "EXECUTANDO");

        paused = false;
        logLines.clear();
        newLogLines.clear();
        droppedLogLines = 0;

    * Metodo: onFrame
    * Funcao: a cada quadro, avanca o tempo virtual pelo tempo real
    *         decorrido vezes o fator de velocidade e atualiza a tela.
    * Parametros: now = instante do quadro em nanossegundos
    * Retorno: void
    *************************************************************** */
    private void onFrame(long now) {
        if (simulator == null) {
            return;
        }//fim do if
        if (paused || lastFrameNanos == 0L) {
            lastFrameNanos = now;
            return;
        }//fim do if
        double elapsedMillis = (now - lastFrameNanos) / 1000000.0;
        lastFrameNanos = now;
        if (elapsedMillis > MAX_FRAME_MS) {
            elapsedMillis = MAX_FRAME_MS;
        }//fim do if
        virtualClock += elapsedMillis * controlPanel.getSpeed();
        simulator.advanceTo((long) virtualClock);
        refreshView();
        // entrega log a view no maximo 1x por frame
        deliverLogIfNeeded();
    }//fim do metodo onFrame

            snapshotShown = true;

            controlPanel.setDestinoAtingido(simulator.getSnapshotCounter(), clock);
            resultsTable.addResult(controlPanel.getVersion(), simulator.getSnapshotCounter());
            graphPane.setDestinationReached(true);

            timer.stop();
            controlPanel.setEstado(view.ControlPanel.EstadoSimulacao.ENCERRADO);
            controlPanel.setState("ENCERRADO");

                controlPanel.setStatus("Encerrada: nao ha mais pacotes na rede.");
            } else {
                controlPanel.setStatus("Encerrada sem atingir o destino (rede esvaziou).");
                resultsTable.addFailure(controlPanel.getVersion(), "INALCANCAVEL");
            }
        }//fim do if
    }//fim do metodo refreshView

    * Metodo: runBatch
    * Funcao: executa o lote de simulacoes em thread de fundo.
    *         O lote NAO instala listener.
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    private void runBatch() {
        final int version = controlPanel.getVersion();
        final int sourceId = controlPanel.getSourceId();
        final int destinationId = controlPanel.getDestinationId();
        final int ttl = controlPanel.getTtl();
        final int count = controlPanel.getBatchCount();
        final long baseSeed = controlPanel.getSeed();
        final long windowMs = controlPanel.getWindowMs();

        if (sourceId == destinationId) {
            controlPanel.setStatus("Escolha transmissor e receptor diferentes.");
            return;
        }

        controlPanel.setEstado(view.ControlPanel.EstadoSimulacao.LOTE);
        controlPanel.setState("LOTE");
        controlPanel.setStatus("Executando lote...");
        controlPanel.setBatchProgress(0, count);

        Task<Void> task = new Task<Void>() {
            @Override
            protected Void call() {
                for (int i = 0; i < count; i++) {
                    if (isCancelled()) {
                        break;
                    }
                    final long seed = baseSeed + i;
                    final int current = i + 1;

                    controller.BatchResult result = controller.BatchRunner.run(
                            graphPane.getGraph(), version, sourceId, destinationId, ttl, 1, seed, windowMs);

                    if (result.getSamples().size() > 0) {
                        final long snapshot = result.getSamples().get(0);
                        Platform.runLater(() -> {
                            resultsTable.addResult(version, snapshot);
                            controlPanel.setBatchProgress(current, count);
                        });
                    } else if (result.getAborted() > 0) {
                        Platform.runLater(() -> {
                            resultsTable.addFailure(version, "ABORTADA");
                            controlPanel.setBatchProgress(current, count);
                        });
                    } else if (result.getUnreachable() > 0) {
                        Platform.runLater(() -> {
                            resultsTable.addFailure(version, "INALCANCAVEL");
                            controlPanel.setBatchProgress(current, count);
                        });
                    } else {
                        Platform.runLater(() -> {
                            controlPanel.setBatchProgress(current, count);
                        });
                    }
                }
                return null;
            }

            @Override
            protected void succeeded() {
                controlPanel.setEstado(view.ControlPanel.EstadoSimulacao.OCIOSO);
                controlPanel.setState("PRONTO");
                controlPanel.setStatus("Lote concluido.");
            }

            @Override
            protected void failed() {
                controlPanel.setEstado(view.ControlPanel.EstadoSimulacao.OCIOSO);
                controlPanel.setState("ERRO");
                controlPanel.setStatus("Erro no lote: " + getException().getMessage());
            }

            @Override
            protected void cancelled() {
                controlPanel.setEstado(view.ControlPanel.EstadoSimulacao.OCIOSO);
                controlPanel.setState("PRONTO");
                controlPanel.setStatus("Lote cancelado.");
            }
        };

        Thread thread = new Thread(task);
        thread.setDaemon(true);
        thread.start();
    }//fim do metodo runBatch
}//fim da classe SimulationController

package model;

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Deque;
import java.util.List;

/**
 * Grafo nao direcionado da rede. Nos com ids em [1..N]; cada link aparece
 * uma unica vez e e indexado por id.
 */
public class Graph {

    private final int nodeCount;
    private final List<Node> nodes = new ArrayList<Node>();
    private final List<Link> links = new ArrayList<Link>();
    // adjacencia: para cada no, lista de links incidentes
    private final List<List<Link>> adjacency = new ArrayList<List<Link>>();

    /* ***************************************************************
* Metodo: Graph
* Funcao: Construtor do grafo com o numero de nos especificado.
* Parametros: nodeCount - numero de nos da rede.
* Retorno: void
*************************************************************** */
public Graph(int nodeCount) {
        if (nodeCount < 1) {
            throw new IllegalArgumentException("Numero de nos deve ser >= 1: " + nodeCount);
        }
        this.nodeCount = nodeCount;
        for (int i = 1; i <= nodeCount; i++) {
            nodes.add(new Node(i));
            adjacency.add(new ArrayList<Link>());
        }
    }

    /* ***************************************************************
* Metodo: getNodeCount
* Funcao: Retorna o numero total de nos no grafo.
* Parametros: nenhum
* Retorno: int - numero de nos.
*************************************************************** */
public int getNodeCount() {
        return nodeCount;
    }

    /* ***************************************************************
* Metodo: getNodes
* Funcao: Retorna uma lista imutavel de nos do grafo.
* Parametros: nenhum
* Retorno: List<Node> - lista de nos.
*************************************************************** */
public List<Node> getNodes() {
        return Collections.unmodifiableList(nodes);
    }

    /* ***************************************************************
* Metodo: getLinks
* Funcao: Retorna uma lista imutavel de links do grafo.
* Parametros: nenhum
* Retorno: List<Link> - lista de links.
*************************************************************** */
public List<Link> getLinks() {
        return Collections.unmodifiableList(links);
    }

    /* ***************************************************************
* Metodo: getNode
* Funcao: Retorna o no com o id especificado.
* Parametros: id - identificador do no (1..N).
* Retorno: Node - o no correspondente.
*************************************************************** */
public Node getNode(int id) {
        return nodes.get(id - 1);
    }

    /** Links incidentes ao no (suas "interfaces"). */
    public List<Link> linksOf(int nodeId) {
        return Collections.unmodifiableList(adjacency.get(nodeId - 1));
    }

    public Link addLink(int a, int b, int weight) {
        validateNodeId(a);
        validateNodeId(b);
        if (a == b) {
            throw new IllegalArgumentException("Link de um no para ele mesmo: " + a);
        }
        Link link = new Link(links.size(), a, b, weight);
        links.add(link);
        adjacency.get(a - 1).add(link);
        adjacency.get(b - 1).add(link);
        return link;
    }

    private void validateNodeId(int id) {
        if (id < 1 || id > nodeCount) {
            throw new IllegalArgumentException(
                    "Id de no fora do intervalo [1.." + nodeCount + "]: " + id);
        }
    }

    /** Distancia em saltos (BFS) entre dois nos; -1 se inalcancavel. */
    public int hopDistance(int from, int to) {
        int[] visited = new int[nodeCount + 1]; // 0 = nao visitado; guarda distancia+1
        Deque<Integer> queue = new ArrayDeque<Integer>();
        queue.add(from);
        visited[from] = 1;
        while (!queue.isEmpty()) {
            int current = queue.poll();
            if (current == to) return visited[current] - 1;
            for (Link link : adjacency.get(current - 1)) {
                int next = link.other(current);
                if (visited[next] == 0) {
                    visited[next] = visited[current] + 1;
                    queue.add(next);
                }
            }
        }
        return -1;
    }

    /** Diametro do grafo em saltos (maior distancia minima entre dois nos). */
    public int diameter() {
        int max = 0;
        for (int i = 1; i <= nodeCount; i++) {
            for (int j = i + 1; j <= nodeCount; j++) {
                max = Math.max(max, hopDistance(i, j));
            }
        }
        return max;
    }
}

/**

 */
public class Link {

    private final int id;
    private final int a;
    private final int b;
    private final int weight;
    private boolean enabled = true;

    /* ***************************************************************
* Metodo: Link
* Funcao: Construtor de link com ids e peso especificados.
* Parametros: id - identificador do link; a, b - nos conectados; weight - peso/metrica.
* Retorno: void
*************************************************************** */

        this.id = id;
        this.a = a;
        this.b = b;
        this.weight = weight;
    }

    public int getId() {
        return id;
    }

    public int getA() {
        return a;
    }

    public int getB() {
        return b;
    }

    public int getWeight() {
        return weight;
    }

    public boolean isEnabled() {
        return enabled;
    }

    public void setEnabled(boolean enabled) {
        this.enabled = enabled;
    }

    /** Retorna o id do no oposto a {@code nodeId} neste link. */
    public int other(int nodeId) {

    }

    @Override
    public String toString() {
        return a + "-" + b + " (peso " + weight + (enabled ? "" : ", desabilitado") + ")";

/* ***************************************************************
* Autor............: Juan Prado Da Silva
* Matricula........: 202310291
* Inicio...........: 01/10/2026
* Ultima alteracao.: 06/10/2026
* Nome.............: Simulator
* Funcao...........: Nucleo da simulacao em tempo virtual.
*************************************************************** */
package model;

import model.Graph;
import model.Link;

import java.util.ArrayList;
import java.util.List;
import java.util.PriorityQueue;

/**
 * Nucleo da simulacao em TEMPO VIRTUAL: fila de eventos (PriorityQueue por
 * instante de chegada, desempate FIFO). Sem Thread.sleep e sem threads.
 *
 * Semantica da chegada de um pacote no no n no instante t:
 *   1) se o link foi desabilitado enquanto o pacote estava nele: descarte;
 *   2) se n e o receptor e ainda nao ha snapshot: registra (contador, t);
 *   3) pergunta a estrategia por quais interfaces reenviar
 *      (o receptor TAMBEM reencaminha);
 *   4) para cada copia enviada: contador++ e chegada agendada em
 *      t + LatencyProvider.nextLatencyMs().
 *
 * Inicio: o transmissor gera uma copia por interface; cada copia conta
 * como 1 pacote gerado.
 *
 * Uso pull-based pela GUI: advanceTo(tempoVirtual) e inFlight().
 * Modo em lote: runUntilFirstArrival().
 */
public class Simulator {

    /** Trava de seguranca do modo em lote: limite de transmissoes. */
    public static final long ABORT_LIMIT = 2000000L;

    /** Evento de chegada agendado de um pacote em um no. */
    private static final class Arrival implements Comparable<Arrival> {
        final long time;
        final long departureTime;
        final long seq; // desempate FIFO
        final int nodeId;
        final int fromNode; // no que enviou esta copia
        final Packet packet;
        final Link link; // link em que o pacote esta em transito

        Arrival(long time, long departureTime, long seq, int nodeId, int fromNode,
                Packet packet, Link link) {
            this.time = time;
            this.departureTime = departureTime;
            this.seq = seq;
            this.nodeId = nodeId;
            this.fromNode = fromNode;
            this.packet = packet;
            this.link = link;
        }

        @Override
        public int compareTo(Arrival other) {
            if (time != other.time) return Long.compare(time, other.time);
            return Long.compare(seq, other.seq);
        }
    }

    /** Pacote em transito em um link, para desenho na GUI. */
    public static final class InFlight {
        public final Packet packet;
        public final Link link;
        public final long departureTime;
        public final long arrivalTime;
        public final int fromNode; // no que enviou esta copia

        InFlight(Packet p, Link link, long dep, long arr, int fromNode) {
            this.packet = p;
            this.link = link;
            this.departureTime = dep;
            this.arrivalTime = arr;
            this.fromNode = fromNode;
        }

        /** Fracao [0,1] do percurso no instante t. */
        public double progress(long t) {
            if (t <= departureTime) return 0.0;
            if (t >= arrivalTime) return 1.0;
            return (double) (t - departureTime) / (double) (arrivalTime - departureTime);
        }
    }

    /** Listener opcional de eventos (usado pelo ConsoleRunner). */
    public interface Listener {
        /** Uma copia enviada em um link: contador ja incrementado. */
        void onTransmit(long time, int fromNode, Link link, Packet packet, long counter);

        /** Pacote chegou ao no destino do link (antes de qualquer processamento). */
        void onArrive(long time, int nodeId, Link link, Packet packet, long counter);
    }

    /** Novo listener com suporte a descartes e primeira chegada. */
    private SimulationListener simListener;

    private final Graph graph;
    private final ForwardingStrategy strategy;
    private final LatencyProvider latency;
    private final int sourceId;
    private final int destinationId;
    private final int initialTtl;

    private final PriorityQueue<Arrival> queue = new PriorityQueue<Arrival>();
    private long virtualTime = 0;
    private long packetsGenerated = 0;
    private long nextSeq = 0;
    private long nextPacketId = 0;
    private boolean started = false;

    // snapshot da primeira chegada ao destino
    private boolean snapshotTaken = false;
    private long snapshotCounter = -1;
    private long snapshotTime = -1;

    private Listener listener;

    public Simulator(Graph graph, ForwardingStrategy strategy, LatencyProvider latency,
                     int sourceId, int destinationId, int initialTtl) {
        this.graph = graph;
        this.strategy = strategy;
        this.latency = latency;
        this.sourceId = sourceId;
        this.destinationId = destinationId;
        this.initialTtl = initialTtl;
    }

    public void setListener(Listener listener) {
        this.listener = listener;
    }

    /**
     * Define o listener com suporte a eventos de descarte e primeira chegada.
     * Pode ser null (nenhum custo).
     * @param simListener listener ou null
     */
    public void setListener(SimulationListener simListener) {
        this.simListener = simListener;
    }

    public ForwardingStrategy getStrategy() {
        return strategy;
    }

    public long getVirtualTime() {
        return virtualTime;
    }

    public long getPacketsGenerated() {
        return packetsGenerated;
    }

    public boolean hasSnapshot() {
        return snapshotTaken;
    }

    public long getSnapshotCounter() {
        return snapshotCounter;
    }

    public long getSnapshotTime() {
        return snapshotTime;
    }

    /**
     * Retorna o tempo do proximo evento na fila, ou Long.MAX_VALUE se vazia.
     * @return tempo virtual do proximo evento ou Long.MAX_VALUE
     */
    public long peekNextTime() {
        if (queue.isEmpty()) {
            return Long.MAX_VALUE;
        }
        return queue.peek().time;
    }

    /** Injetor inicial: uma copia por interface do transmissor. */
    public void start() {
        if (started) return;
        started = true;
        // V4: registra messageId na origem em t=0
        if (strategy instanceof model.Strategy4Custom) {
            model.Strategy4Custom s4 = (model.Strategy4Custom) strategy;
            // Unico messageId para a mensagem logica desta execucao
            long msgId = nextPacketId++;
            s4.registrarNaOrigem(msgId, sourceId, virtualTime);
            for (Link link : graph.linksOf(sourceId)) {
                if (!link.isEnabled()) continue;
                Packet p = new Packet(nextPacketId++, msgId, initialTtl, null);
                transmit(virtualTime, sourceId, link, p);
            }
        } else {
            for (Link link : graph.linksOf(sourceId)) {
                if (!link.isEnabled()) continue;
                Packet p = new Packet(nextPacketId++, 0, initialTtl, null);
                transmit(virtualTime, sourceId, link, p);
            }
        }
        virtualTime = Math.max(virtualTime, 0);
    }

    private void transmit(long time, int fromNode, Link link, Packet packet) {
        packetsGenerated++;
        int to = link.other(fromNode);
        long arrival = time + latency.nextLatencyMs();
        // a copia que viaja carrega a interface de chegada e o messageId do original
        Packet travelling = new Packet(nextPacketId++, packet.getMessageId(), packet.getTtl(), link);
        travelling.setArrivalTime(arrival);
        queue.add(new Arrival(arrival, time, nextSeq++, to, fromNode, travelling, link));
        if (listener != null) {
            listener.onTransmit(time, fromNode, link, packet, packetsGenerated);
        }
        if (simListener != null) {
            simListener.onSend(time, fromNode, link, packet, packetsGenerated);
        }
    }

    /** Avanca o tempo virtual ate t (inclusive), processando eventos. */
    public void advanceTo(long t) {
        start();
        while (!queue.isEmpty() && queue.peek().time <= t) {
            process(queue.poll());
        }
        virtualTime = Math.max(virtualTime, t);
    }

    /** Processa eventos ate a primeira chegada ao destino ou a fila esvaziar. */
    public RunResult runUntilFirstArrival() {
        start();
        boolean abortedByLimit = false;
        while (!hasSnapshot() && !queue.isEmpty()) {
            if (packetsGenerated > ABORT_LIMIT) {
                abortedByLimit = true;
                break;
            }
            advanceTo(queue.peek().time);
        }
        return new RunResult(hasSnapshot(), snapshotCounter, snapshotTime,
                packetsGenerated, virtualTime, abortedByLimit);
    }

    private void process(Arrival ev) {
        virtualTime = Math.max(virtualTime, ev.time);
        // 1) link desabilitado enquanto o pacote estava nele: descarte
        if (!ev.link.isEnabled()) {
            if (simListener != null) {
                simListener.onDrop(ev.time, ev.nodeId, ev.link, ev.packet,
                        packetsGenerated, SimulationListener.DROP_LINK);
            }
            return;
        }
        if (listener != null) {
            listener.onArrive(ev.time, ev.nodeId, ev.link, ev.packet, packetsGenerated);
        }
        if (simListener != null) {
            simListener.onArrive(ev.time, ev.nodeId, ev.link, ev.packet, packetsGenerated);
        }
        // 2) snapshot na primeira chegada ao receptor
        if (ev.nodeId == destinationId && !snapshotTaken) {
            snapshotTaken = true;
            snapshotCounter = packetsGenerated;
            snapshotTime = ev.time;
            if (simListener != null) {
                simListener.onFirstArrival(ev.time, destinationId, snapshotCounter, ev.packet);
            }
        }
        // 3) e 4) a estrategia decide; o receptor TAMBEM reencaminha
        List<Link> out = strategy.forward(graph, ev.nodeId, ev.packet);
        String dropReason = strategy.getLastDropReason();
        if (dropReason != null && simListener != null) {
            simListener.onDrop(ev.time, ev.nodeId, ev.link, ev.packet,
                    packetsGenerated, dropReason);
        }
        for (Link link : out) {
            transmit(ev.time, ev.nodeId, link, ev.packet);
        }//fim do for
    }

    /** Pacotes atualmente em transito (para desenho da GUI). */
    public List<InFlight> inFlight() {
        List<InFlight> list = new ArrayList<InFlight>();
        for (Arrival ev : queue) {
            list.add(new InFlight(ev.packet, ev.link, ev.departureTime, ev.time, ev.fromNode));
        }
        return list;
    }
}

            if (link.isEnabled() && link != packet.getArrivalLink()) {
                out.add(link);
            }
        }
        return out;
    }

    @Override
    public String getLastDropReason() {
        return lastDropReason;
    }
}

    *************************************************************** */
    public Strategy4Custom() {
        this(1000);
    }

    /* ***************************************************************
    * Metodo: Strategy4Custom
    * Funcao: Construtor com janela de deduplicacao especificada.
    * Parametros: janelaMs - janela em milissegundos
    * Retorno: void
    *************************************************************** */
    public Strategy4Custom(long janelaMs) {
        this.janelaMs = janelaMs;
        this.visto = new HashMap<Integer, Map<Long, Long>>();
        this.duplicatasDescartadas = 0;
    }

    /* ***************************************************************
    * Metodo: registrarNaOrigem
    * Funcao: Registra um messageId na origem em t=0 (para V4).
    *          O registro e feito per-no: o messageId e marcado como visto
    *          no no especificado no instante t.
 * Parametros: messageId - id logico da mensagem; nodeId - no da origem;
 *             t - instante virtual.
 * Retorno: void
 *************************************************************** */
    public void registrarNaOrigem(long messageId, int nodeId, long t) {
        visto.computeIfAbsent(nodeId, k -> new HashMap<Long, Long>())
             .put(messageId, t);
    }

    /* ***************************************************************
    * Metodo: getDuplicatasDescartadas
    * Funcao: Retorna o numero de duplicatas descartadas nesta execucao.
    * Parametros: nenhum
    * Retorno: long - contador de duplicatas.
    *************************************************************** */
    public long getDuplicatasDescartadas() {
        return duplicatasDescartadas;
    }

    /* ***************************************************************
    * Metodo: forward
    * Funcao: Decide por quais interfaces do no o pacote sera retransmitido.
 * Em V4, ANTES da logica de TTL, verifica deduplicacao por janela de tempo.
 * Se a copia for duplicata dentro da janela, descarta (retorna lista vazia).
 * Caso contrario, atualiza o registro e aplica a logica V3 (decremento de TTL,
 * reenvio exceto pela interface de chegada).
 * Parametros: graph - topologia da rede; nodeId - no que recebeu o pacote;
 *           packet - pacote recebido (pode ser alterado).
 * Retorno: links por onde retransmitir; lista vazia = descartar.
 *************************************************************** */
    @Override
    public List<Link> forward(Graph graph, int nodeId, Packet packet) {
        long t = packet.getArrivalTime();

        // Get or create the per-node visto map
        Map<Long, Long> nodeVisto = visto.computeIfAbsent(nodeId, k -> new HashMap<Long, Long>());

        Long instanteVisto = nodeVisto.get(packet.getMessageId());
        if (instanteVisto != null && (t - instanteVisto) < janelaMs) {
            // Duplicate within window - discard, DO NOT update visto
            duplicatasDescartadas++;
            lastDropReason = SimulationListener.DROP_DUPLICATE;
            return new ArrayList<Link>();
        }

        // Not a duplicate (outside window or first observation): update visto
        // and apply V3 logic. A duplicata NAO renova o registro, entao so
        // atualizamos quando a copia nao e duplicata.
        nodeVisto.put(packet.getMessageId(), t);

        // V3 logic: decrement TTL
        packet.setTtl(packet.getTtl() - 1);
        if (packet.getTtl() <= 0) {
            lastDropReason = SimulationListener.DROP_TTL;
            return new ArrayList<Link>(); // descarta por TTL expirado
        }

        lastDropReason = null;
        List<Link> out = new ArrayList<Link>();
        for (Link link : graph.linksOf(nodeId)) {
            if (link.isEnabled() && link != packet.getArrivalLink()) {
                out.add(link);
            }
        }
        return out;
    }

    @Override
    public String getLastDropReason() {
        return lastDropReason;
    }
}

package util;

import model.Graph;

import java.io.BufferedReader;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;

/**
 * Carrega o arquivo backbone.txt:
 *   1a linha: numero de nos (pode ter ';' final, ex.: "8;").
 *   Demais:   NO1;NO2;PESO  - aresta nao direcionada, listada uma unica vez.
 * Linhas em branco e espacos sao ignorados. Ids validados em [1..N].
 */
public final class BackboneLoader {

    private BackboneLoader() {
    }

    public static Graph load(Path file) throws IOException {
        try (BufferedReader reader = Files.newBufferedReader(file, StandardCharsets.UTF_8)) {
            String firstLine = null;
            String line;
            while ((line = reader.readLine()) != null) {
                line = line.trim();
                if (!line.isEmpty()) {
                    firstLine = line;
                    break;
                }
            }
            if (firstLine == null) {
                throw new IOException("Arquivo backbone vazio: " + file);
            }
            if (firstLine.endsWith(";")) {
                firstLine = firstLine.substring(0, firstLine.length() - 1).trim();
            }
            int nodeCount;
            try {
                nodeCount = Integer.parseInt(firstLine);
            } catch (NumberFormatException e) {
                throw new IOException("Primeira linha deve conter o numero de nos: '"
                        + firstLine + "'", e);
            }
            Graph graph = new Graph(nodeCount);

            int lineNumber = 1;
            while ((line = reader.readLine()) != null) {
                lineNumber++;
                line = line.trim();
                if (line.isEmpty()) continue;
                String[] parts = line.split(";");
                if (parts.length != 3) {
                    throw new IOException("Linha " + lineNumber + ": esperado NO1;NO2;PESO, "
                            + "encontrado '" + line + "'");
                }
                try {
                    int a = Integer.parseInt(parts[0].trim());
                    int b = Integer.parseInt(parts[1].trim());
                    int weight = Integer.parseInt(parts[2].trim());
                    graph.addLink(a, b, weight);
                } catch (NumberFormatException e) {
                    throw new IOException("Linha " + lineNumber + ": valor nao numerico em '"
                            + line + "'", e);
                } catch (IllegalArgumentException e) {
                    throw new IOException("Linha " + lineNumber + ": " + e.getMessage(), e);
                }
            }
            return graph;
        }
    }
}

/**
 * Utilitario de console para simulacao de flooding.
 * Uso: java -cp build util.ConsoleRunner <versao> <origem> <destino> <ttl> <semente> [backbone] [janela=<ms>]
 * Imprime um evento por linha e o snapshot da primeira chegada ao destino.
 * O argumento janela=<ms> e opcional, pode aparecer em qualquer posicao apos o 5o argumento.
 * So e usado na versao 4; padrao = 1000 ms.

public final class ConsoleRunner {

    private ConsoleRunner() {
    }

    private static ForwardingStrategy strategyFor(int version, long janelaMs) {
        switch (version) {
            case 1: return new Strategy1AllInterfaces();
            case 2: return new Strategy2ExceptIncoming();
            case 3: return new Strategy3Ttl();
            case 4: return new Strategy4Custom(janelaMs);
            default:
                throw new IllegalArgumentException("Versao invalida (1..4): " + version);
        }
    }

    private static String route(Link link, int fromNode) {
        return link.getA() + "-" + link.getB() + " (" + fromNode + "->" + link.other(fromNode) + ")";
    }

    public static void main(String[] args) throws Exception {
        if (args.length < 5) {
            System.err.println("Uso: ConsoleRunner <versao> <origem> <destino> <ttl> <semente> [backbone] [janela=<ms>]");
            System.exit(2);
        }
        final int version = Integer.parseInt(args[0]);
        final int source = Integer.parseInt(args[1]);
        final int destination = Integer.parseInt(args[2]);
        final int ttl = Integer.parseInt(args[3]);
        final long seed = Long.parseLong(args[4]);

        // Parse optional arguments: backbone file and janela=<ms>
        Path file = Paths.get("backbone.txt");
        long janelaMs = 1000; // default for V4

        for (int i = 5; i < args.length; i++) {
            String arg = args[i];
            if (arg.startsWith("janela=")) {
                try {
                    janelaMs = Long.parseLong(arg.substring(7));
                } catch (NumberFormatException e) {
                    System.err.println("Valor invalido para janela: " + arg);
                    System.exit(2);
                }
            } else {
                file = Paths.get(arg);
            }
        }

        Graph graph = BackboneLoader.load(file);
        final boolean showTtl = version >= 3;

        ForwardingStrategy strategy = strategyFor(version, janelaMs);
        Simulator sim = new Simulator(graph, strategy,
                new LatencyProvider(seed), source, destination, ttl);

        sim.setListener(new Simulator.Listener() {
            @Override
            public void onTransmit(long time, int fromNode, Link link, Packet packet, long counter) {
                System.out.printf("t=%6d  ENVIO    link %-12s %s contador=%d%n",
                        time, route(link, fromNode), ttlInfo(packet), counter);
            }

            @Override
            public void onArrive(long time, int nodeId, Link link, Packet packet, long counter) {
                System.out.printf("t=%6d  CHEGADA  link %-12s no=%d %s contador=%d%n",
                        time, route(link, link.other(nodeId)), nodeId, ttlInfo(packet), counter);
            }

            private String ttlInfo(Packet p) {
                return showTtl ? "ttl=" + p.getTtl() + " " : "";
            }
        });

        RunResult result = sim.runUntilFirstArrival();

        System.out.println();
        if (result.isReached()) {
            System.out.println("SNAPSHOT: primeira chegada ao destino " + destination
                    + " em t=" + result.getSnapshotTime()
                    + " ms com contador=" + result.getSnapshotCounter() + " pacotes gerados.");
        } else if (result.isAbortedByLimit()) {
            System.out.println("ABORTADO: limite de " + Simulator.ABORT_LIMIT
                    + " transmissoes excedido sem chegada ao destino.");
        } else {
            System.out.println("DESTINO INALCANCAVEL: fila de eventos esvaziou sem chegada.");
        }
        System.out.println("Total de pacotes gerados: " + result.getPacketsGenerated()
                + "  |  tempo virtual final: " + result.getVirtualTime() + " ms");

        // V4: imprimir duplicatas descartadas
        if (version == 4) {
            ForwardingStrategy strat = sim.getStrategy();
            if (strat instanceof model.Strategy4Custom) {
                System.out.println("Duplicatas descartadas: " + ((model.Strategy4Custom) strat).getDuplicatasDescartadas());
            }
        }
    }
}

package util;

/**
 * Utilitario para rotulos de nos.
 * Conversao: 1->A, 2->B, ..., 26->Z, 27->N27, 28->N28, etc.
 */
public final class NodeLabelUtil {

    private NodeLabelUtil() {
    }

    /* ***************************************************************
    * Metodo: toLabel
    * Funcao: Converte id numerico para rotulo alfabetico.
    * Parametros: id - identificador do no (1-based)
    * Retorno: String - rotulo (A-Z para 1-26, N27+ para maiores)
    *************************************************************** */
    public static String toLabel(int id) {
        if (id >= 1 && id <= 26) {
            return String.valueOf((char) ('A' + id - 1));
        }
        return "N" + id;
    }

    /* ***************************************************************
    * Metodo: fromLabel
    * Funcao: Converte rotulo alfabetico para id numerico (inverso de toLabel).
    *         So suporta formato A-Z e N27+.
    * Parametros: label - rotulo do no
    * Retorno: int - id numerico ou -1 se invalido
    *************************************************************** */
    public static int fromLabel(String label) {
        if (label == null || label.isEmpty()) {
            return -1;
        }
        if (label.length() == 1) {
            char c = label.charAt(0);
            if (c >= 'A' && c <= 'Z') {
                return c - 'A' + 1;
            }
        }
        if (label.startsWith("N")) {
            try {
                return Integer.parseInt(label.substring(1));
            } catch (NumberFormatException e) {
                return -1;
            }
        }
        return -1;
    }
}

package util;

import java.util.List;

/**
 * Utilitarios estatisticos para List<Long>.
 * Calcula mean e standard deviation amostral.
 * Lista vazia devolve 0.0; mean com 1 elemento devolve o proprio valor.
 * standardDeviation com menos de 2 elementos devolve 0.0.
 */
public final class Statistics {

    private Statistics() {
    }

    /* ***************************************************************
    * Metodo: mean
    * Funcao: Calcula a media aritmetica dos valores.
    * Parametros: valores - Lista de valores Long.
    * Retorno: media dos valores, ou 0.0 se a lista estiver vazia.
    *          Se a lista tem um elemento, devolve o proprio valor.
    *************************************************************** */
    public static double mean(List<Long> values) {
        if (values == null || values.isEmpty()) {
            return 0.0;
        }
        long sum = 0;
        for (Long v : values) {
            sum += v;
        }
        return (double) sum / values.size();
    }

    /* ***************************************************************
    * Metodo: standardDeviation
    * Funcao: Calcula o desvio-padrao amostral dos valores.
    * Parametros: valores - Lista de valores Long.
    * Retorno: desvio-padrao amostral, ou 0.0 se a lista estiver vazia ou ter
    *          menos de 2 elementos.
    *************************************************************** */
    public static double standardDeviation(List<Long> values) {
        if (values == null || values.isEmpty() || values.size() < 2) {
            return 0.0;
        }
        double avg = mean(values);
        double sumSqDiff = 0.0;
        for (Long v : values) {
            double diff = v - avg;
            sumSqDiff += diff * diff;
        }
        return Math.sqrt(sumSqDiff / (values.size() - 1));
    }
}

  /* ***************************************************************
  * Metodo: updateForNewGraph
  * Funcao: Atualiza os combos de origem/destino para novo grafo
  * Parametros: newGraph - novo grafo carregado
  * Retorno: void
  *************************************************************** */
  public void updateForNewGraph(Graph newGraph) {
    int currentSource = sourceCombo.getValue();
    int currentTarget = targetCombo.getValue();
    sourceCombo.getItems().clear();
    targetCombo.getItems().clear();
    for (int i = 1; i <= newGraph.getNodeCount(); i++) {
      sourceCombo.getItems().add(i);
      targetCombo.getItems().add(i);
    }
    if (sourceCombo.getItems().contains(currentSource)) {
      sourceCombo.setValue(currentSource);
    } else {
      sourceCombo.setValue(1);
    }
    if (targetCombo.getItems().contains(currentTarget)) {
      targetCombo.setValue(currentTarget);
    } else {
      targetCombo.setValue(newGraph.getNodeCount());
    }
    int diameter = newGraph.diameter();
    ttlSpinner.setValueFactory(new SpinnerValueFactory.IntegerSpinnerValueFactory(1, 100, diameter));
  }

  /* ***************************************************************
  * Metodo: setStatus
  * Funcao: Define mensagem de status e atualiza label de finalizada se necessario
  * Parametros: msg - mensagem
  * Retorno: void
  *************************************************************** */
  public void setStatus(String msg) {
    if (overlayFinishedLabel != null) {
      final String message = msg;
      Platform.runLater(() -> {
        if (message.contains("Encerrada") && message.contains("pacotes na rede")) {
          overlayFinishedLabel.setText("Encerrada: nao ha mais pacotes na rede.");
          overlayFinishedLabel.setVisible(true);
          overlayFinishedLabel.setManaged(true);
        } else if (message.contains("Encerrada sem atingir")) {
          overlayFinishedLabel.setText("Encerrada sem atingir o destino (rede esvaziou).");
          overlayFinishedLabel.setVisible(true);
          overlayFinishedLabel.setManaged(true);
        } else {
          overlayFinishedLabel.setVisible(false);
          overlayFinishedLabel.setManaged(false);
        }
      });
    }
  }

  * Parametros: running - true se executando, false se pausado

    if (running) {

  /* ***************************************************************
  * Metodo: atualizarBotoes
  * Funcao: Atualiza o estado dos botoes com base no estado explicito
  *         da simulacao.
  * Parametros: nenhum
  * Retorno: void
  *************************************************************** */
  private void atualizarBotoes() {
    switch (estadoAtual) {
      case OCIOSO:
        startBtn.setDisable(false);
        Theme.styleFlatButtonFilled(startBtn);
        pauseBtn.setDisable(true);
        pauseBtn.setText("PAUSAR");
        Theme.styleButtonDisabled(pauseBtn);
        resetBtn.setDisable(true);
        Theme.styleButtonDisabled(resetBtn);
        stepBtn.setDisable(false);
        Theme.styleFlatButtonOutlined(stepBtn);
        break;
      case RODANDO:
        startBtn.setDisable(true);
        Theme.styleButtonDisabled(startBtn);
        pauseBtn.setDisable(false);
        pauseBtn.setText("PAUSAR");
        Theme.styleFlatButtonOutlined(pauseBtn);
        resetBtn.setDisable(false);
        Theme.styleFlatButtonOutlined(resetBtn);
        stepBtn.setDisable(true);
        Theme.styleButtonDisabled(stepBtn);
        break;

                    setText(null);
                } else {
                    setFont(Theme.FONT_12);
                    setTextFill(javafx.scene.paint.Color.web(Theme.TEXT));
                    setText(item);

    * Parametros: lines = linhas a adicionar

    public void addLines(List<String> lines) {
        for (String line : lines) {

            nodePulses.put(nodeId, System.nanoTime());
        }
    }//fim do metodo pulse

    /* ***************************************************************
    * Metodo: showPackets
    * Funcao: redesenha pacotes em transito no Canvas unico.
    *         Cada pacote: ponto raio 3 em #fe8019 alpha 0.85.
    *         TTL: monoespaçado 12px se <= 150 pacotes e showTtl=true.
    *         Tambem desenha pulsos de atividade no pulseCanvas.
    * Parametros: flights = pacotes em transito; virtualTime = relogio virtual
    *             showTtl = true para exibir TTL
    * Retorno: void
    *************************************************************** */
    public void showPackets(List<Simulator.InFlight> flights,
            long virtualTime, boolean showTtl) {
        double w = getWidth();
        double h = getHeight();

        // Calcular conjunto de links com pacotes em transito
        Set<Link> newActiveLinks = new HashSet<Link>();
        for (Simulator.InFlight flight : flights) {
            newActiveLinks.add(flight.link);
        }

        // So redesenha cabos se o conjunto de links ativos mudou
        if (!newActiveLinks.equals(activeLinks)) {
            activeLinks.clear();
            activeLinks.addAll(newActiveLinks);
            drawLinks();
        }

        // Pacotes no packetsCanvas
        GraphicsContext gcPkt = packetsCanvas.getGraphicsContext2D();
        gcPkt.clearRect(0, 0, w, h);

        boolean drawTtl = showTtl && flights.size() <= MAX_PACKETS_FOR_TTL;

        if (drawTtl) {
            gcPkt.setFont(Font.font("Monospaced", FontWeight.BOLD, TTL_FONT_SIZE));
            gcPkt.setFill(Theme.TEXT_COLOR);
        }

        // Pacotes: preenchimento #fe8019, contorno 1px #1d2021, raio 4
        Color packetFill = Theme.ORANGE_ACCENT_COLOR; // #fe8019
        Color packetStroke = Theme.BG_COLOR;          // #1d2021

        for (Simulator.InFlight flight : flights) {
            Link link = flight.link;
            int fromId = flight.fromNode;
            int toId = link.other(fromId);
            double progress = flight.progress(virtualTime);
            if (progress < 0.0) progress = 0.0;
            if (progress > 1.0) progress = 1.0;
            double fromX = nodeX[fromId - 1];
            double fromY = nodeY[fromId - 1];
            double x = fromX + (nodeX[toId - 1] - fromX) * progress;
            double y = fromY + (nodeY[toId - 1] - fromY) * progress;

            // Contorno
            gcPkt.setStroke(packetStroke);
            gcPkt.setLineWidth(1.0);
            gcPkt.strokeOval(x - PACKET_RADIUS, y - PACKET_RADIUS,
                    PACKET_RADIUS * 2.0, PACKET_RADIUS * 2.0);
            // Preenchimento
            gcPkt.setFill(packetFill);
            gcPkt.fillOval(x - PACKET_RADIUS, y - PACKET_RADIUS,
                    PACKET_RADIUS * 2.0, PACKET_RADIUS * 2.0);

            if (drawTtl) {
                gcPkt.setFont(Font.font("Monospaced", FontWeight.BOLD, TTL_FONT_SIZE));
                // Calcular vetor perpendicular ao cabo para deslocamento
                double dx = nodeX[toId - 1] - fromX;
                double dy = nodeY[toId - 1] - fromY;
                double len = Math.hypot(dx, dy);
                double px = 0, py = 0;
                if (len > 0) {
                    // Perpendicular (rotacionado 90 graus): (-dy, dx) normalizado
                    px = -dy / len * TTL_OFFSET_PERP;
                    py = dx / len * TTL_OFFSET_PERP;
                }
                String ttlText = Integer.toString(flight.packet.getTtl());
                // Contorno escuro
                gcPkt.setStroke(Theme.BG_COLOR);
                gcPkt.setLineWidth(2.0);
                gcPkt.strokeText(ttlText, x + px, y + py);
                // Preenchimento
                gcPkt.setFill(Theme.TEXT_COLOR);
                gcPkt.fillText(ttlText, x + px, y + py);
            }
        }

        // Pulsos no pulseCanvas (chamado a cada frame pela animacao)
        drawPulses();
    }//fim do metodo showPackets

    /* ***************************************************************
    * Metodo: drawPulses
    * Funcao: desenha pulsos de atividade no pulseCanvas.
    *         Hexagono expandido com fade-out baseado no tempo real.
    *         Remove pulsos expirados.
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    private void drawPulses() {
        double w = getWidth();
        double h = getHeight();
        GraphicsContext gc = pulseCanvas.getGraphicsContext2D();
        gc.clearRect(0, 0, w, h);

        long now = System.nanoTime();
        Color pulseColorBase = Theme.ORANGE_ACCENT_COLOR;

        for (int i = 0; i < nodeX.length; i++) {
            int nodeId = i + 1;
            Long pulseTime = nodePulses.get(nodeId);
            if (pulseTime == null) continue;

            long elapsed = now - pulseTime;
            if (elapsed >= PULSE_DURATION_NS) {
                nodePulses.remove(nodeId);
                continue;
            }

            double progress = (double) elapsed / PULSE_DURATION_NS;
            double cx = nodeX[i];
            double cy = nodeY[i];
            double r = currentHexR + PULSE_MAX_EXPANSION * progress;
            double alpha = 1.0 - progress;
            gc.setStroke(Color.web(Theme.ORANGE_ACCENT, alpha));
            gc.setLineWidth(PULSE_STROKE_WIDTH);

            // Desenha hexagono no Canvas
            gc.beginPath();
            for (int v = 0; v < 6; v++) {
                double angle = Math.toRadians(30 + v * 60);
                double x = cx + r * Math.cos(angle);
                double y = cy + r * Math.sin(angle);
                if (v == 0) gc.moveTo(x, y);
                else gc.lineTo(x, y);
            }
            gc.closePath();
            gc.stroke();
        }
    }//fim do metodo drawPulses

    /* ***************************************************************
    * Metodo: clearPackets
    * Funcao: limpa o Canvas de pacotes, Canvas de pulsos e estados.
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    public void clearPackets() {
        GraphicsContext gcPkt = packetsCanvas.getGraphicsContext2D();
        GraphicsContext gcPulse = pulseCanvas.getGraphicsContext2D();
        double w = getWidth();
        double h = getHeight();
        if (w > 0 && h > 0) {
            gcPkt.clearRect(0, 0, w, h);
            gcPulse.clearRect(0, 0, w, h);
        }
        nodePulses.clear();
    }//fim do metodo clearPackets

    /* ***************************************************************
    * Metodo: pulseClearNow
    * Funcao: zera imediatamente o mapa de pulsos e limpa o canvas de pulsos.

    public void pulseClearNow() {

    /* ***************************************************************

    /* ***************************************************************
    * Metodo: computeLayout
    * Funcao: posiciona os nos em circulo, centralizados no painel.
    *         Calcula raio do hexagono e fonte proporcionais ao tamanho.
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    private void computeLayout() {
        int count = graph.getNodeCount();
        nodeX = new double[count];
        nodeY = new double[count];
        weightLabelPositions.clear();
        double centerX = getWidth() / 2.0;
        double centerY = getHeight() / 2.0;

        double availableRadius = Math.min(getWidth(), getHeight()) / 2.0 - MARGIN;

        double minRadiusForNodes;
        if (count <= 1) {
            minRadiusForNodes = 0;
        } else {
            double angleBetween = Math.PI / count;
            minRadiusForNodes = (HEX_R_MAX + HEX_GAP / 2.0) / Math.sin(angleBetween);
        }

        double layoutRadius = Math.max(availableRadius, minRadiusForNodes);

        if (layoutRadius > 0) {
            double ratio = Math.min(1.0, layoutRadius / 300.0);
            currentHexR = HEX_R_MIN + (HEX_R_MAX - HEX_R_MIN) * ratio;
            currentLabelSize = LABEL_MIN_SIZE + (LABEL_MAX_SIZE - LABEL_MIN_SIZE) * ratio;
        } else {
            currentHexR = HEX_R_MIN;
            currentLabelSize = LABEL_MIN_SIZE;
        }

        for (int i = 0; i < count; i++) {
            double angle = 2.0 * Math.PI * i / count - Math.PI / 2.0;
            nodeX[i] = centerX + layoutRadius * Math.cos(angle);
            nodeY[i] = centerY + layoutRadius * Math.sin(angle);
        }
    }//fim do metodo computeLayout

    /* ***************************************************************
    * Metodo: drawBackground
    * Funcao: desenha grade discreta e seta norte no Canvas de fundo.
    *         So redesenha se tamanho mudou.
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    private void drawBackground() {
        if (!bgNeedsRedraw) return;
        double w = getWidth();
        double h = getHeight();
        if (w <= 0 || h <= 0) return;
        GraphicsContext gc = bgCanvas.getGraphicsContext2D();
        gc.clearRect(0, 0, w, h);
        gc.setFill(Theme.BG_COLOR);
        gc.fillRect(0, 0, w, h);
        gc.setStroke(Theme.GRID_COLOR);
        gc.setLineWidth(0.5);
        for (double x = 0; x <= w; x += GRID_SIZE) {
            gc.strokeLine(x, 0, x, h);
        }
        for (double y = 0; y <= h; y += GRID_SIZE) {
            gc.strokeLine(0, y, w, y);
        }
        double cx = 40.0;
        double cy = 40.0;
        double s = 12.0;
        gc.setStroke(Theme.TEXT_SECONDARY_COLOR);
        gc.setFill(Theme.TEXT_SECONDARY_COLOR);
        gc.setLineWidth(1.5);
        gc.strokeLine(cx, cy + s, cx, cy - s);
        gc.strokeLine(cx, cy - s, cx - s / 2.0, cy - s / 2.0);
        gc.strokeLine(cx, cy - s, cx + s / 2.0, cy - s / 2.0);
        gc.setFont(Font.font("Monospaced", FontWeight.BOLD, 10));
        gc.fillText("N", cx - 3, cy - s - 4);
        bgNeedsRedraw = false;
    }//fim do metodo drawBackground

    /* ***************************************************************
    * Metodo: drawLinks
    * Funcao: desenha TODOS os cabos primeiro (contorno #504945 + nucleo),
    *         nucleo em repouso bege #a89984, nucleo ativo laranja #fe8019,
    *         desabilitado: tracejado #665c54 com X vermelho no meio.
    *         So redesenha quando o conjunto de links ativos muda.
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    private void drawLinks() {
        linksLayer.getChildren().clear();
        Color outerColor = Theme.BORDER_COLOR;           // #504945
        Color coreRestColor = Theme.TEXT_SECONDARY_COLOR; // #a89984 (bege) - repouso
        Color coreActiveColor = Theme.ORANGE_ACCENT_COLOR; // #fe8019 (laranja) - ativo
        Color disabledColor = Theme.INACTIVE_COLOR;       // #665c54

        // Calcular posicoes das placas de peso se ainda nao calculadas (carregamento ou resize)
        boolean needCalc = weightLabelPositions.isEmpty();
        if (needCalc) {
            weightLabelPositions.clear();
            for (Link link : graph.getLinks()) {
                double cx = (nodeX[link.getA() - 1] + nodeX[link.getB() - 1]) / 2.0;
                double cy = (nodeY[link.getA() - 1] + nodeY[link.getB() - 1]) / 2.0;
                double t = calcularMelhorPosicaoPeso(link, cx, cy);
                weightLabelPositions.put(link, t);
            }
        }

        for (Link link : graph.getLinks()) {
            double x1 = nodeX[link.getA() - 1];
            double y1 = nodeY[link.getA() - 1];
            double x2 = nodeX[link.getB() - 1];
            double y2 = nodeY[link.getB() - 1];

            Line outer = new Line(x1, y1, x2, y2);
            outer.setStrokeWidth(7.0);
            outer.setStrokeLineCap(StrokeLineCap.ROUND);
            outer.setMouseTransparent(true);
            outer.setStroke(outerColor);

            Line core = new Line(x1, y1, x2, y2);
            core.setStrokeWidth(3.0);
            core.setStrokeLineCap(StrokeLineCap.ROUND);
            core.setMouseTransparent(true);

            Line hitArea = new Line(x1, y1, x2, y2);
            hitArea.setStrokeWidth(HIT_WIDTH);
            hitArea.setStroke(Color.TRANSPARENT);
            hitArea.setCursor(Cursor.HAND);

            if (link.isEnabled()) {
                boolean isActive = activeLinks.contains(link);
                core.setStroke(isActive ? coreActiveColor : coreRestColor);
            } else {
                outer.setStroke(disabledColor);
                outer.getStrokeDashArray().addAll(10.0, 6.0);
                core.setStroke(disabledColor);
                core.getStrokeDashArray().addAll(10.0, 6.0);
                double mx = (x1 + x2) / 2.0;
                double my = (y1 + y2) / 2.0;
                double cut = 10.0;
                Line cut1 = new Line(mx - cut, my - cut, mx + cut, my + cut);
                Line cut2 = new Line(mx - cut, my + cut, mx + cut, my - cut);
                cut1.setStroke(Theme.RED_COLOR);
                cut1.setStrokeWidth(2.0);
                cut2.setStroke(Theme.RED_COLOR);
                cut2.setStrokeWidth(2.0);
                cut1.setMouseTransparent(true);
                cut2.setMouseTransparent(true);
                linksLayer.getChildren().addAll(cut1, cut2);
            }

            hitArea.setOnMouseClicked(event -> {
                link.setEnabled(!link.isEnabled());
                drawLinks();
            });

            linksLayer.getChildren().addAll(outer, core, hitArea);
        }

        // Desenhar placas de peso nas posicoes calculadas
        for (Link link : graph.getLinks()) {
            double x1 = nodeX[link.getA() - 1];
            double y1 = nodeY[link.getA() - 1];
            double x2 = nodeX[link.getB() - 1];
            double y2 = nodeY[link.getB() - 1];
            double t = weightLabelPositions.getOrDefault(link, 0.5);
            double cx = x1 + (x2 - x1) * t;
            double cy = y1 + (y2 - y1) * t;
            addWeightLabel(link.getWeight(), cx, cy, link.isEnabled(), t);
        }
    }//fim do metodo drawLinks

    /* ***************************************************************
    * Metodo: addWeightLabel
    * Funcao: placa de peso retangular com borda 1px, fundo painel,
    *         texto amarelo monoespacado.
    * Parametros: weight = peso; cx, cy = ponto medio; enabled = link ativo
    * Retorno: void
    *************************************************************** */
    private void addWeightLabel(int weight, double cx, double cy, boolean enabled, double t) {
        Text text = new Text(String.valueOf(weight));
        text.setFont(Font.font("Monospaced", FontWeight.BOLD, 12));
        text.setFill(enabled ? Theme.YELLOW_COLOR : Theme.TEXT_SECONDARY_COLOR);
        double width = text.getLayoutBounds().getWidth();
        double height = text.getLayoutBounds().getHeight();
        double padX = 8.0;
        double padY = 3.0;

        double rh = height + 2 * padY;
        Rectangle bg = new Rectangle(cx - rw / 2.0, cy - rh / 2.0, rw, rh);
        bg.setFill(Theme.PANEL_COLOR);

        bg.setStrokeWidth(1.0);
        bg.setMouseTransparent(true);

        text.setX(cx - width / 2.0);
        text.setY(cy + height / 4.0);
        linksLayer.getChildren().addAll(bg, text);
    }//fim do metodo addWeightLabel

    /* ***************************************************************
    * Metodo: calcularMelhorPosicaoPeso
    * Funcao: encontra a melhor posicao t ao longo do cabo para a placa
    *         de peso, evitando cruzamentos com outros cabos.
    *         Testa t = 0.5, 0.4, 0.6, 0.3, 0.7; usa o primeiro onde
    *         a placa fica a mais de WEIGHT_LABEL_MIN_DIST de qualquer
    *         outro cabo. Se nenhum, usa 0.5.
    * Parametros: link = link atual; cx, cy = ponto medio do link
    * Retorno: double t (0..1) ao longo do cabo
    *************************************************************** */
    private double calcularMelhorPosicaoPeso(Link link, double cx, double cy) {
        double x1 = nodeX[link.getA() - 1];
        double y1 = nodeY[link.getA() - 1];
        double x2 = nodeX[link.getB() - 1];
        double y2 = nodeY[link.getB() - 1];
        double dx = x2 - x1;
        double dy = y2 - y1;
        double len = Math.hypot(dx, dy);
        if (len == 0) return 0.5;

        // Criar um texto temporario para medir dimensoes
        Text tempText = new Text(String.valueOf(link.getWeight()));
        tempText.setFont(Font.font("Monospaced", FontWeight.BOLD, 12));
        double width = tempText.getLayoutBounds().getWidth();
        double height = tempText.getLayoutBounds().getHeight();
        double padX = 8.0;
        double padY = 3.0;
        double rw = width + 2 * padX;
        double rh = height + 2 * padY;

        for (double t : WEIGHT_LABEL_T_CANDIDATES) {
            double tx = x1 + dx * t;
            double ty = y1 + dy * t;

            // Verificar distancia a todos os outros cabos
            boolean ok = true;
            for (Link other : graph.getLinks()) {
                if (other == link) continue;
                double ox1 = nodeX[other.getA() - 1];
                double oy1 = nodeY[other.getA() - 1];
                double ox2 = nodeX[other.getB() - 1];
                double oy2 = nodeY[other.getB() - 1];

                // Distancia do ponto (tx, ty) ao segmento (ox1,oy1)-(ox2,oy2)
                double odx = ox2 - ox1;
                double ody = oy2 - oy1;
                double olen2 = odx * odx + ody * ody;
                double dist;
                if (olen2 == 0) {
                    dist = Math.hypot(tx - ox1, ty - oy1);
                } else {
                    double u = ((tx - ox1) * odx + (ty - oy1) * ody) / olen2;
                    u = Math.max(0, Math.min(1, u));
                    double closestX = ox1 + u * odx;
                    double closestY = oy1 + u * ody;
                    dist = Math.hypot(tx - closestX, ty - closestY);
                }

                if (dist < WEIGHT_LABEL_MIN_DIST + Math.max(rw, rh) / 2.0) {
                    ok = false;
                    break;
                }
            }
            if (ok) return t;
        }
        return 0.5;
    }//fim do metodo calcularMelhorPosicaoPeso

    /* ***************************************************************
    * Metodo: drawNodes
    * Funcao: desenha nos como hexagonos ponta-para-cima (raio proporcional
    *         18-32, preenchimento #3c3836, borda 2px #a89984). Rotulo mono
    *         negrito proporcional (>=14). TX/RX como placas preenchidas.
    *         Destino atingido: borda laranja 4px.
    *         NAO desenha pulsos aqui (feito no pulseCanvas em showPackets).
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    private void drawNodes() {
        nodesLayer.getChildren().clear();
        List<model.Node> nodes = graph.getNodes();
        double r = currentHexR;
        double labelSize = currentLabelSize;
        double tagSize = 12.0;
        double tagPadX = 8.0;
        double tagPadY = 3.0;

        for (int i = 0; i < nodes.size(); i++) {
            int id = nodes.get(i).getId();
            double cx = nodeX[i];
            double cy = nodeY[i];

            Polygon hex = new Polygon();
            for (int v = 0; v < 6; v++) {
                double angle = Math.toRadians(30 + v * 60);
                hex.getPoints().addAll(
                    cx + r * Math.cos(angle),
                    cy + r * Math.sin(angle)
                );
            }
            hex.setFill(Theme.HEADER_COLOR);

            boolean isDest = destinationReached && id == destinationId;
            if (id == sourceId) {
                hex.setStroke(Theme.TX_COLOR_OBJ);
            } else if (id == destinationId) {
                hex.setStroke(Theme.RX_COLOR_OBJ);
            } else {
                hex.setStroke(Theme.TEXT_SECONDARY_COLOR);
            }
            hex.setStrokeWidth(isDest ? 4.0 : 2.0);
            if (isDest) {
                hex.setStroke(Theme.ORANGE_ACCENT_COLOR);
            }
            hex.setMouseTransparent(true);

            Text label = new Text(nodes.get(i).getLabel());
            label.setFont(Font.font("Monospaced", FontWeight.BOLD, labelSize));
            label.setFill(Theme.TEXT_COLOR);
            label.setTextOrigin(VPos.CENTER);
            label.setX(cx - label.getLayoutBounds().getWidth() / 2.0);
            label.setY(cy);
            label.setMouseTransparent(true);

            if (id == sourceId || id == destinationId) {
                String tagText = (id == sourceId) ? "TX" : "RX";
                Color tagFill = (id == sourceId) ? Theme.TX_COLOR_OBJ : Theme.RX_COLOR_OBJ;
                Color tagTextColor = Theme.TEXT_COLOR;

                Text tag = new Text(tagText);
                tag.setFont(Font.font("Monospaced", FontWeight.BOLD, tagSize));
                tag.setFill(tagTextColor);
                double tw = tag.getLayoutBounds().getWidth();
                double th = tag.getLayoutBounds().getHeight();
                double trw = tw + 2 * tagPadX;
                double trh = th + 2 * tagPadY;
                Rectangle tagBg = new Rectangle(
                    cx - trw / 2.0,
                    cy + r + 6.0,
                    trw, trh
                );
                tagBg.setFill(tagFill);
                tagBg.setStroke(Theme.BORDER_COLOR);
                tagBg.setStrokeWidth(1.0);
                tagBg.setArcWidth(4.0);
                tagBg.setArcHeight(4.0);
                tagBg.setMouseTransparent(true);
                tag.setMouseTransparent(true);
                tag.setX(cx - tw / 2.0);
                tag.setY(cy + r + 6.0 + trh / 2.0 + th / 4.0);
                nodesLayer.getChildren().addAll(tagBg, tag);
            }

            nodesLayer.getChildren().addAll(hex, label);
        }
    }//fim do metodo drawNodes

    /* ***************************************************************
    * Metodo: drawLegend
    * Funcao: desenha legenda compacta no canto inferior direito.
    *         Itens: TX, RX, cabo em repouso, cabo ativo, cabo cortado,
    *                pacote (ponto c/ contorno), pulso (anel contorno).
    *         Texto 12px monoespacado, baixo contraste, nao interativo.
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    private void drawLegend() {
        legendLayer.getChildren().clear();

        double w = getWidth();
        double h = getHeight();
        if (w <= 0 || h <= 0) return;

        Font legendFont = Font.font("Monospaced", FontWeight.NORMAL, LEGEND_FONT_SIZE);
        Color textColor = Theme.TEXT_SECONDARY_COLOR; // baixo contraste

        // Itens da legenda: {cor do simbolo, texto, tipo}
        class LegendItem {
            Color color;
            String text;
            int type; // 0=filled rect (TX/RX), 1=line (cable), 2=dashed line with X, 3=filled circle with stroke (packet), 4=pulse ring
            LegendItem(Color c, String t, int tp) { color = c; text = t; type = tp; }
        }

        LegendItem[] items = new LegendItem[] {
            new LegendItem(Theme.TX_COLOR_OBJ, "TX", 0),
            new LegendItem(Theme.RX_COLOR_OBJ, "RX", 0),
            new LegendItem(Theme.TEXT_SECONDARY_COLOR, "cabo em repouso", 1),   // bege #a89984
            new LegendItem(Theme.ORANGE_ACCENT_COLOR, "cabo ativo", 1),           // laranja #fe8019
            new LegendItem(Theme.INACTIVE_COLOR, "cabo cortado", 2),              // tracejado #665c54 c/ X
            new LegendItem(Theme.ORANGE_ACCENT_COLOR, "pacote", 3),               // ponto laranja c/ contorno #1d2021
            new LegendItem(Theme.ORANGE_ACCENT_COLOR, "pulso", 4)                 // anel contorno
        };

        // Calcula largura total da legenda
        double maxTextWidth = 0;
        for (LegendItem item : items) {
            Text t = new Text(item.text);
            t.setFont(legendFont);
            double tw = t.getLayoutBounds().getWidth();
            if (tw > maxTextWidth) maxTextWidth = tw;
        }
        double legendWidth = LEGEND_PADDING * 2 + LEGEND_SYMBOL_SIZE + LEGEND_GAP + maxTextWidth;
        double legendHeight = LEGEND_PADDING * 2 + items.length * LEGEND_ITEM_HEIGHT;

        // Posicao: canto inferior direito com margem
        double margin = 16.0;
        double startX = w - legendWidth - margin;
        double startY = h - legendHeight - margin;

        // Fundo semi-transparente
        Rectangle bg = new Rectangle(startX, startY, legendWidth, legendHeight);
        bg.setFill(Color.web(Theme.PANEL, 0.85));
        bg.setStroke(Theme.BORDER_COLOR);
        bg.setStrokeWidth(1.0);
        bg.setArcWidth(4.0);
        bg.setArcHeight(4.0);
        bg.setMouseTransparent(true);
        legendLayer.getChildren().add(bg);

        // Itens
        double y = startY + LEGEND_PADDING + LEGEND_ITEM_HEIGHT * 0.75; // baseline aproximado
        for (LegendItem item : items) {
            double symX = startX + LEGEND_PADDING + LEGEND_SYMBOL_SIZE / 2.0;
            double symY = y - LEGEND_ITEM_HEIGHT / 2.5;

            if (item.type == 4) {
                // Pulso: hexagono so contorno laranja
                Polygon p = new Polygon();
                double pr = LEGEND_SYMBOL_SIZE / 2.0;
                for (int v = 0; v < 6; v++) {
                    double angle = Math.toRadians(30 + v * 60);
                    p.getPoints().addAll(
                        symX + pr * Math.cos(angle),
                        symY + pr * Math.sin(angle)
                    );
                }
                p.setFill(null);
                p.setStroke(item.color);
                p.setStrokeWidth(2.0);
                p.setStrokeLineCap(StrokeLineCap.ROUND);
                p.setMouseTransparent(true);
                legendLayer.getChildren().add(p);
            } else if (item.type == 2) {
                // Cabo cortado: linha tracejada cinza #665c54 com X
                Line l = new Line(symX - LEGEND_SYMBOL_SIZE / 2.0, symY, symX + LEGEND_SYMBOL_SIZE / 2.0, symY);
                l.setStroke(item.color);
                l.setStrokeWidth(2.5);
                l.getStrokeDashArray().addAll(6.0, 4.0);
                l.setMouseTransparent(true);
                legendLayer.getChildren().add(l);
                // X no meio
                Line x1 = new Line(symX - 4, symY - 4, symX + 4, symY + 4);
                Line x2 = new Line(symX - 4, symY + 4, symX + 4, symY - 4);
                x1.setStroke(Theme.RED_COLOR);
                x1.setStrokeWidth(1.5);
                x2.setStroke(Theme.RED_COLOR);
                x2.setStrokeWidth(1.5);
                x1.setMouseTransparent(true);
                x2.setMouseTransparent(true);
                legendLayer.getChildren().addAll(x1, x2);
            } else if (item.type == 3) {
                // Pacote: ponto cheio laranja #fe8019 com contorno 1px #1d2021
                Circle c = new Circle(symX, symY, LEGEND_SYMBOL_SIZE / 2.5);
                c.setFill(item.color);
                c.setStroke(Theme.BG_COLOR); // #1d2021
                c.setStrokeWidth(1.0);
                c.setMouseTransparent(true);
                legendLayer.getChildren().add(c);
            } else if (item.type == 1) {
                // Cabo: linha horizontal (bege ou laranja)
                Line l = new Line(symX - LEGEND_SYMBOL_SIZE / 2.0, symY, symX + LEGEND_SYMBOL_SIZE / 2.0, symY);
                l.setStroke(item.color);
                l.setStrokeWidth(3.0);
                l.setStrokeLineCap(StrokeLineCap.ROUND);
                l.setMouseTransparent(true);
                legendLayer.getChildren().add(l);
            } else {
                // TX/RX: retangulo preenchido
                Rectangle r = new Rectangle(symX - LEGEND_SYMBOL_SIZE / 2.0, symY - LEGEND_SYMBOL_SIZE / 3.0, LEGEND_SYMBOL_SIZE, LEGEND_SYMBOL_SIZE * 0.6);
                r.setFill(item.color);
                r.setStroke(Theme.BORDER_COLOR);
                r.setStrokeWidth(1.0);
                r.setArcWidth(2.0);
                r.setArcHeight(2.0);
                r.setMouseTransparent(true);
                legendLayer.getChildren().add(r);
            }

            // Texto
            Text t = new Text(item.text);
            t.setFont(legendFont);
            t.setFill(textColor);
            t.setX(symX + LEGEND_SYMBOL_SIZE / 2.0 + LEGEND_GAP);
            t.setY(symY + 4.0);
            t.setMouseTransparent(true);
            legendLayer.getChildren().add(t);

            y += LEGEND_ITEM_HEIGHT;
        }
    }//fim do metodo drawLegend

}//fim da classe GraphPane

/* ***************************************************************

package view;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import javafx.beans.property.ReadOnlyObjectWrapper;
import javafx.beans.property.SimpleIntegerProperty;
import javafx.beans.property.SimpleLongProperty;
import javafx.beans.property.SimpleStringProperty;
import javafx.collections.FXCollections;
import javafx.collections.ObservableList;
import javafx.scene.Node;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.TableColumn;
import javafx.scene.control.TableRow;
import javafx.scene.control.TableView;
import javafx.scene.control.Tooltip;
import util.Statistics;

/**
 * Tabela de resultados com 4 linhas fixas (V1 a V4).
 * Cada versao acumula uma lista de snapshots validos e contadores
 * de falhas (inalcancaveis e abortadas).
 */
public final class ResultsTable {

    private static class RowData {
        private final int version;
        private final List<Long> samples = new ArrayList<Long>();
        private long lastSnapshot = 0;
        private int unreachable = 0;
        private int aborted = 0;

        RowData(int version) {
            this.version = version;
        }
    }

    // Callback para notificar mudancas (ex.: redesenhar grafico)
    private Runnable onChangeCallback;
    private boolean logScale = true;

    private final RowData[] rows = new RowData[4];
    private final ObservableList<RowData> items = FXCollections.observableArrayList();
    private final TableView<RowData> table = new TableView<RowData>();
    private final Button clearButton = new Button("LIMPAR");

    /* ***************************************************************
    * Metodo: ResultsTable
    * Funcao: construtor; cria a tabela com colunas e 4 linhas fixas.
    * Parametros: nenhum
    * Retorno: nao se aplica
    *************************************************************** */
    public ResultsTable() {
        for (int i = 0; i < 4; i++) {
            rows[i] = new RowData(i + 1);
            items.add(rows[i]);
        }

        table.setItems(items);
        // Politica de redimensionamento restrita: colunas nao encolhem alem do minimo,
        // sem barra de rolagem horizontal.
        table.setColumnResizePolicy(TableView.CONSTRAINED_RESIZE_POLICY);

        // Coluna V (versao) - largura 38
        TableColumn<RowData, String> colVersion = new TableColumn<RowData, String>("");
        colVersion.setCellValueFactory(cell -> new SimpleStringProperty("V" + cell.getValue().version));
        colVersion.setCellFactory(col -> new TableCellMonospace());
        colVersion.setPrefWidth(38);
        colVersion.setMinWidth(38);
        colVersion.setMaxWidth(38);
        colVersion.setResizable(false);
        Label hdrVersion = new Label("V");
        hdrVersion.setTooltip(new Tooltip("VERSAO"));
        colVersion.setGraphic(hdrVersion);

        // Coluna ULT (ultima execucao) - largura 56
        TableColumn<RowData, Long> colLast = new TableColumn<RowData, Long>("");
        colLast.setCellValueFactory(cell -> new SimpleLongProperty(cell.getValue().lastSnapshot).asObject());
        colLast.setCellFactory(col -> new TableCellMonospace());
        colLast.setPrefWidth(56);
        colLast.setMinWidth(56);
        colLast.setMaxWidth(56);
        colLast.setResizable(false);
        Label hdrLast = new Label("ULT");
        hdrLast.setTooltip(new Tooltip("ULTIMA EXECUCAO"));
        colLast.setGraphic(hdrLast);

        // Coluna N (quantidade de execucoes validas) - largura 40
        TableColumn<RowData, Integer> colN = new TableColumn<RowData, Integer>("");
        colN.setCellValueFactory(cell -> new SimpleIntegerProperty(cell.getValue().samples.size()).asObject());
        colN.setCellFactory(col -> new TableCellMonospace());
        colN.setPrefWidth(40);
        colN.setMinWidth(40);
        colN.setMaxWidth(40);
        colN.setResizable(false);
        Label hdrN = new Label("N");
        hdrN.setTooltip(new Tooltip("QUANTIDADE DE EXECUCOES VALIDAS"));
        colN.setGraphic(hdrN);

        // Coluna MEDIA - largura 64
        TableColumn<RowData, Double> colMean = new TableColumn<RowData, Double>("");
        colMean.setCellValueFactory(cell -> {
            double m = Statistics.mean(cell.getValue().samples);
            return new ReadOnlyObjectWrapper<Double>(m);
        });
        colMean.setCellFactory(col -> new TableCellMonospace());
        colMean.setPrefWidth(64);
        colMean.setMinWidth(64);
        colMean.setMaxWidth(64);
        colMean.setResizable(false);
        Label hdrMean = new Label("MEDIA");
        hdrMean.setTooltip(new Tooltip("MEDIA DOS SNAPSHOTS"));
        colMean.setGraphic(hdrMean);

        // Coluna DESV (desvio padrao) - largura 60
        TableColumn<RowData, Double> colStdDev = new TableColumn<RowData, Double>("");
        colStdDev.setCellValueFactory(cell -> {
            double s = Statistics.standardDeviation(cell.getValue().samples);
            return new ReadOnlyObjectWrapper<Double>(s);
        });
        colStdDev.setCellFactory(col -> new TableCellMonospace());
        colStdDev.setPrefWidth(60);
        colStdDev.setMinWidth(60);
        colStdDev.setMaxWidth(60);
        colStdDev.setResizable(false);
        Label hdrStdDev = new Label("DESV");
        hdrStdDev.setTooltip(new Tooltip("DESVIO PADRAO"));
        colStdDev.setGraphic(hdrStdDev);

        // Coluna MIN - largura 50
        TableColumn<RowData, Long> colMin = new TableColumn<RowData, Long>("");
        colMin.setCellValueFactory(cell -> {
            List<Long> s = cell.getValue().samples;
            long v = (s.isEmpty()) ? 0 : Collections.min(s);
            return new SimpleLongProperty(v).asObject();
        });
        colMin.setCellFactory(col -> new TableCellMonospace());
        colMin.setPrefWidth(50);
        colMin.setMinWidth(50);
        colMin.setMaxWidth(50);
        colMin.setResizable(false);
        Label hdrMin = new Label("MIN");
        hdrMin.setTooltip(new Tooltip("VALOR MINIMO"));
        colMin.setGraphic(hdrMin);

        // Coluna MAX - largura 50
        TableColumn<RowData, Long> colMax = new TableColumn<RowData, Long>("");
        colMax.setCellValueFactory(cell -> {
            List<Long> s = cell.getValue().samples;
            long v = (s.isEmpty()) ? 0 : Collections.max(s);
            return new SimpleLongProperty(v).asObject();
        });
        colMax.setCellFactory(col -> new TableCellMonospace());
        colMax.setPrefWidth(50);
        colMax.setMinWidth(50);
        colMax.setMaxWidth(50);
        colMax.setResizable(false);
        Label hdrMax = new Label("MAX");
        hdrMax.setTooltip(new Tooltip("VALOR MAXIMO"));
        colMax.setGraphic(hdrMax);

        // Coluna INAL (inalcancaveis) - largura 56
        TableColumn<RowData, Integer> colUnreachable = new TableColumn<RowData, Integer>("");
        colUnreachable.setCellValueFactory(cell -> new SimpleIntegerProperty(cell.getValue().unreachable).asObject());
        colUnreachable.setCellFactory(col -> new TableCellMonospace());
        colUnreachable.setPrefWidth(56);
        colUnreachable.setMinWidth(56);
        colUnreachable.setMaxWidth(56);
        colUnreachable.setResizable(false);
        Label hdrUnreachable = new Label("INAL");
        hdrUnreachable.setTooltip(new Tooltip("INALCANCAVEIS"));
        colUnreachable.setGraphic(hdrUnreachable);

        // Coluna ABOR (abortadas) - largura 56
        TableColumn<RowData, Integer> colAborted = new TableColumn<RowData, Integer>("");
        colAborted.setCellValueFactory(cell -> new SimpleIntegerProperty(cell.getValue().aborted).asObject());
        colAborted.setCellFactory(col -> new TableCellMonospace());
        colAborted.setPrefWidth(56);
        colAborted.setMinWidth(56);
        colAborted.setMaxWidth(56);
        colAborted.setResizable(false);
        Label hdrAborted = new Label("ABOR");
        hdrAborted.setTooltip(new Tooltip("ABORTADAS"));
        colAborted.setGraphic(hdrAborted);

        table.getColumns().addAll(colVersion, colLast, colN, colMean, colStdDev, colMin, colMax, colUnreachable, colAborted);

        // Altura fixa de linha: 28px
        table.setFixedCellSize(28.0);
        // Altura total = cabecalho (28) + 4 linhas * 28 = 140px
        // Sem linhas vazias, sem barra vertical.
        double tableHeight = 28.0 + 4 * 28.0;
        table.setPrefHeight(tableHeight);
        table.setMinHeight(tableHeight);
        table.setMaxHeight(tableHeight);

        // Zebra striping via row factory
        table.setRowFactory(tv -> new TableRow<RowData>() {
            @Override
            protected void updateItem(RowData item, boolean empty) {
                super.updateItem(item, empty);
                if (empty || item == null) {
                    setStyle("");
                } else {
                    int idx = getIndex();
                    String baseColor = (idx % 2 == 0) ? Theme.PANEL : Theme.HEADER;
                    if (isSelected()) {
                        setStyle("-fx-background-color: " + Theme.ORANGE_FILL + "; -fx-text-fill: " + Theme.BG + ";");
                    } else {
                        setStyle("-fx-background-color: " + baseColor + "; -fx-text-fill: " + Theme.TEXT + ";");
                    }
                }
            }
        });

        // Header style
        table.getStylesheets().clear();
        Theme.styleTableView(table);

        // Aplicar estilo aos cabecalhos das colunas
        for (TableColumn<RowData, ?> col : table.getColumns()) {
            Theme.styleTableColumnHeader(col);
        }

        // Estilizar scrollbars quando a cena estiver disponivel
        table.sceneProperty().addListener((obs, oldScene, newScene) -> {
            if (newScene != null) {
                Theme.styleScrollBars(table);
            }
        });

        Theme.styleFlatButtonOutlined(clearButton);
        clearButton.setOnAction(e -> clear());
    }//fim do construtor ResultsTable

    /**
     * Celula monoespacada com texto amarelo para valores numericos.
     * Respeita selecao de linha (fundo laranja, texto escuro).
     * Fonte 13px.
     */
    private static class TableCellMonospace<S, T> extends javafx.scene.control.TableCell<S, T> {
        private static final javafx.scene.text.Font FONT_13 = Theme.monoFont(13, false);

        @Override
        protected void updateItem(T item, boolean empty) {
            super.updateItem(item, empty);
            if (empty || item == null) {
                setText(null);
                setStyle("");
            } else {
                setFont(FONT_13);
                setText(item.toString());
                // Cor do texto: amarelo para normal, fundo escuro para selecao
                TableRow<S> row = getTableRow();
                if (row != null && row.isSelected()) {
                    setTextFill(javafx.scene.paint.Color.web(Theme.BG));
                } else {
                    setTextFill(javafx.scene.paint.Color.web(Theme.YELLOW));
                }
            }
        }

        @Override
        public void updateSelected(boolean selected) {
            super.updateSelected(selected);
            // Atualiza cor do texto quando selecao muda
            if (!isEmpty() && getItem() != null) {
                if (selected) {
                    setTextFill(javafx.scene.paint.Color.web(Theme.BG));
                } else {
                    setTextFill(javafx.scene.paint.Color.web(Theme.YELLOW));
                }
            }
        }
    }

    /* ***************************************************************
    * Metodo: addResult
    * Funcao: adiciona um snapshot a versao indicada e recalcula.
    * Parametros: versao = 1 a 4; snapshot = contador de pacotes gerados
    * Retorno: void
    *************************************************************** */
    public void addResult(int version, long snapshot) {
        if (version < 1 || version > 4) {
            return;
        }
        RowData row = rows[version - 1];
        row.samples.add(Long.valueOf(snapshot));
        row.lastSnapshot = snapshot;
        table.refresh();
        if (onChangeCallback != null) onChangeCallback.run();
    }//fim do metodo addResult

    /* ***************************************************************
    * Metodo: addFailure
    * Funcao: incrementa contador de falha (inalcancavel ou abortada).
    *         Falhas nao entram na media/desvio/min/max.
    * Parametros: versao = 1 a 4; tipo = "INALCANCAVEL" ou "ABORTADA"
    * Retorno: void
    *************************************************************** */
    public void addFailure(int version, String tipo) {
        if (version < 1 || version > 4) {
            return;
        }
        RowData row = rows[version - 1];
        if ("INALCANCAVEL".equals(tipo)) {
            row.unreachable++;
        } else if ("ABORTADA".equals(tipo)) {
            row.aborted++;
        }
        table.refresh();
        if (onChangeCallback != null) onChangeCallback.run();
    }//fim do metodo addFailure

    /* ***************************************************************
    * Metodo: clear
    * Funcao: limpa todas as amostras e contadores.
    * Parametros: nenhum
    * Retorno: void
    *************************************************************** */
    public void clear() {
        for (RowData row : rows) {
            row.samples.clear();
            row.lastSnapshot = 0;
            row.unreachable = 0;
            row.aborted = 0;
        }
        table.refresh();
        if (onChangeCallback != null) onChangeCallback.run();
    }//fim do metodo clear

    /* ***************************************************************
    * Metodo: setOnChange
    * Funcao: define callback chamado quando os dados mudam.
    * Parametros: callback = Runnable a executar
    * Retorno: void
    *************************************************************** */
    public void setOnChange(Runnable callback) {
        this.onChangeCallback = callback;
    }//fim do metodo setOnChange

    /* ***************************************************************
    * Metodo: getNode
    * Funcao: devolve o TableView para insercao no layout.
    * Parametros: nenhum
    * Retorno: Node da tabela
    *************************************************************** */
    public Node getNode() {
        return table;
    }//fim do metodo getNode

    /* ***************************************************************
    * Metodo: getClearButton
    * Funcao: devolve o botao Limpar para uso externo.
    * Parametros: nenhum
    * Retorno: Button
    *************************************************************** */
    public Button getClearButton() {
        return clearButton;
    }//fim do metodo getClearButton

    /* ***************************************************************
    * Metodo: setLogScale
    * Funcao: define se a escala logaritmica esta ativa (para grafico).
    * Parametros: logScale - true para escala log
    * Retorno: void
    *************************************************************** */
    public void setLogScale(boolean logScale) {
        this.logScale = logScale;
    }//fim do metodo setLogScale

    /* ***************************************************************
    * Metodo: isLogScale
    * Funcao: retorna se a escala logaritmica esta ativa.
    * Parametros: nenhum
    * Retorno: boolean
    *************************************************************** */
    public boolean isLogScale() {
        return logScale;
    }//fim do metodo isLogScale

    /* ***************************************************************
    * Metodo: getSamples
    * Funcao: devolve as amostras de uma versao (para o grafico).
    * Parametros: version = 1 a 4
    * Retorno: List<Long> imutavel
    *************************************************************** */
    public List<Long> getSamples(int version) {
        if (version < 1 || version > 4) {
            return Collections.emptyList();
        }
        return Collections.unmodifiableList(rows[version - 1].samples);
    }//fim do metodo getSamples

}//fim da classe ResultsTable

    /**
     * Aplica estilo a ScrollBar (vertical/horizontal) para tema escuro.
     * Deve ser aplicado apos o controle ser adicionado a cena (ex: via lookup).
     * @param control Controle pai que contem a ScrollBar
     */
    public static void styleScrollBars(javafx.scene.control.Control control) {
        String scrollBarStyle =
            "-fx-background-color: " + BG + ";" +
            "-fx-background-radius: 0;";
        String thumbStyle =
            "-fx-background-color: " + INACTIVE + ";" +
            "-fx-background-radius: 0;" +
            "-fx-background-insets: 2;";
        String trackStyle =
            "-fx-background-color: transparent;" +
            "-fx-background-radius: 0;";
        String incrementStyle =
            "-fx-background-color: transparent;" +
            "-fx-background-radius: 0;";
        String decrementStyle =
            "-fx-background-color: transparent;" +
            "-fx-background-radius: 0;";

        control.applyCss();
        for (javafx.scene.Node node : control.lookupAll(".scroll-bar")) {
            if (node instanceof javafx.scene.control.ScrollBar) {
                javafx.scene.control.ScrollBar sb = (javafx.scene.control.ScrollBar) node;
                sb.setStyle(scrollBarStyle);
                javafx.scene.Node thumb = sb.lookup(".thumb");
                if (thumb != null) thumb.setStyle(thumbStyle);
                javafx.scene.Node track = sb.lookup(".track");
                if (track != null) track.setStyle(trackStyle);
                javafx.scene.Node incBtn = sb.lookup(".increment-button");
                if (incBtn != null) incBtn.setStyle(incrementStyle);
                javafx.scene.Node decBtn = sb.lookup(".decrement-button");
                if (decBtn != null) decBtn.setStyle(decrementStyle);
            }
        }
        for (javafx.scene.Node n : control.lookupAll(".scroll-bar:vertical .thumb")) {
            n.setStyle(thumbStyle);
        }
        for (javafx.scene.Node n : control.lookupAll(".scroll-bar:horizontal .thumb")) {
            n.setStyle(thumbStyle);
        }
    }

    /**
     * Aplica o tema a uma Scene (fundo global).
     * @param scene Scene a estilizar
     */
    public static void apply(javafx.scene.Scene scene) {
        scene.setFill(Color.web(BG));
        String existing = scene.getRoot().getStyle();
        scene.getRoot().setStyle((existing == null || existing.isEmpty() ? "" : existing + ";") + "-fx-background-color: " + BG + ";");
    }
